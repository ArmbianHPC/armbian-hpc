# v1.0.0

- Adds OECT Bookworm firmware with a SATA system and preconfigured SquashFS Rescue A/B.
- Integrates device identity, MAC and hostname setup, Ethernet LEDs, and the USB2 OTG serial console.
- Provides unified system, Rescue, and K3s commands, SATA installation and recovery, and shared clock recovery.
- Includes the OTA runtime and signed system/Rescue update packaging.
- Standardises configurable builds and versioned firmware filenames.
