# K3s 配置

在普通系统运行 `armhpc-kube configuration`，可以创建 SQLite 控制节点、初始化 etcd 集群，或加入已有集群的工作节点、控制节点。`armhpc configuration` 打开同一个应用配置向导。节点名称、版本、集群配置和凭据保存于设备本地。

下载来源提供上游官方来源、自定义 HTTPS 镜像以及 Rancher 中文社区国内源。国内源使用配套安装脚本与程序下载地址，按单独固定的 SHA256 校验安装脚本，并启用其下载路径规则。K3s 版本仍填写 `v1.36.5+k3s1` 等原始版本字符串；国内下载目录内部使用连字符。

安装脚本的网络故障最多尝试三次。证书错误、哈希不一致、脚本超过容量限制和永久 HTTP 错误均拒绝。只有校验通过的脚本才会写入并执行。国内镜像更新安装脚本后，需要通过新的软件修订更新已经审核的校验值。

容器仓库镜像站是独立设置，需要在使用它的各个节点上配置。向导接受 HTTPS 镜像地址，重试保存的配置时保留节点和集群参数。

`armhpc-kube check` 检查 DATA 挂载、节点身份、安装状态及持久目录。下载中断后可使用保存的配置重试。修改来源时选择“2. 修正参数或下载来源”，然后选择“3. Rancher 中文社区国内源”。后续控制节点的关键集群参数必须与第一台一致，包括 Secret 加密设置。

安装脚本和软件来源校验 SHA256 与 HTTPS。集群令牌、凭据和 K3s 上游二进制不进入本仓库或系统 OTA 包；OTA 按记录恢复已安装的同版本 K3s。普通系统从 Rescue 恢复时保留 DATA；集群维护由管理员执行。
