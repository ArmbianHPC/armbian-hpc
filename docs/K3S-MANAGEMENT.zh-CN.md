# K3s 管理

在普通系统的 root SSH 终端执行。

| 命令 | 行为 |
|---|---|
| `armhpc-kube uninstall` | 停止工作负载，归档本机 K3s 数据，卸载并清除向导记录。 |
| `armhpc-kube reinstall` | 完成同样的重置后，重新打开交互式安装向导。 |
| `armhpc-kube clear` | 清理未完成安装；拒绝清理已完成安装或仍在运行的节点。 |

`--preview --json` 只预览，`--yes --json` 用于已确认的批量卸载或清理。重装需要交互式 SSH。`--k3s-version v1.37.1+k3s1` 设置下次安装向导的默认版本。

旧数据、配置、凭据及本地 PV 归档于 `/data/backups/k3s-reset-*`，目录权限为 0700。备份含集群凭据，只保存在设备或私有存储内。中断后重新执行原命令，继续原备份任务。

重建整个集群时，先处理工作节点和其他控制节点，最后处理首台控制节点。首台选择 2 创建集群，达到 Ready 后，其他控制节点选择 4，工作节点选择 3。各节点统一填写完整 K3s 版本。
